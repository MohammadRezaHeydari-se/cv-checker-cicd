# CV Checker

A simple PDF resume checker built with Python and FastAPI.

## Purpose

This project demonstrates an automated CI/CD pipeline
using GitHub Actions, Pytest, and Docker.

## Features

- Upload a PDF resume
- Check for essential CV information
- Display detected and missing fields
- Process files without permanent storage

## Technologies

- Python
- FastAPI
- Pytest
- Docker
- GitHub Actions
